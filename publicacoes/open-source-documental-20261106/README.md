# Biblioteca técnica open-source documental — 06/11/2026

Publicação solicitada por Marina: coleção técnica independente de conteúdo comercial no domínio oficial www.arquindex.com.br e artigo de apresentação no blog.

O payload comprimido contém 19 páginas HTML (18 manuais/índices + 1 artigo), Markdown, CSS/JS, catálogo, exemplos e sitemap. Os hashes e destinos estão no manifest.json. Os instaladores são links oficiais e não são redistribuídos.

O publicador exige FTP com TLS validado e a credencial FTP_PASSWORD já cadastrada. Descobre a raiz comparando o index remoto com o conteúdo público do domínio; recusa destinos preexistentes diferentes; guarda backup exato dos arquivos alterados; insere um bloco identificado no blog e adiciona URLs ao sitemap preservando as entradas existentes. Em erro, reverte apenas arquivos ainda iguais à própria versão recém-enviada. Não altera homepage, DNS, e-mail ou aplicativos.

Os scripts e procedimentos técnicos são documentados; nenhum stack documental foi instalado durante esta publicação. A rotina só informa sucesso depois da leitura pública de todos os arquivos enviados.
