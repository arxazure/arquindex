## Antes de publicar
1. Identificar qual repositório, branch e diretório alimenta cada domínio publicado (HomeHost, Hostinger e Railway).
2. Evitar criar segunda URL para conteúdo já existente. Fazer inventário de URLs e escolher canônicas.
3. Validar contato, marca, capacidade de atendimento, conteúdo local, links e formulários.
4. Implantar páginas no servidor correto; testar status HTTP 200, links, layout móvel e formulário.
5. Substituir robots noindex,follow por index,follow SOMENTE após verificar a URL definitiva e conteúdo útil.
6. Adicionar rel=canonical com a URL pública final; incluir no sitemap XML do host correto.
7. Enviar sitemap pelo Search Console e Bing Webmaster Tools apenas após publicação confirmada.
8. Monitorar impressões, cliques, CTR, consultas, páginas indexadas e leads por região semanalmente.

## Regras de segurança editorial
Não inventar escritório local, depoimento, certificação ou cliente. Não garantir ranking. Não criar páginas municipais praticamente idênticas. Não sobrescrever configuração de produção sem inspecionar deploy existente.
