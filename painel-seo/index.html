Prioridades em andamento

Integridade dos dados

O painel não simula cliques, impressões, rankings ou publicações. Importe um CSV do Google Search Console para iniciar a medição.

Critérios de publicação

Rascunho → Revisão → Na fila → Publicado com URL → Validado com mídia. Status não verificados permanecem pendentes.

Fontes de dados e segurança

Google Search Console: importação CSV manual disponível. Integração automática indisponível até configuração de autenticação autorizada.

Bing Webmaster, GA4 e plataformas sociais: não conectados neste painel. Nenhum dado desses serviços será inventado.

Armazenamento: localStorage do navegador. Não use este MVP como repositório de senhas, tokens ou documentos de clientes.
